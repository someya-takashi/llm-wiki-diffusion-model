# ERNIE-Image: 美的スコアリングを設計の中心に据えた 8B の基盤モデル

> 原典: [[translations/2026-ernie-image]] ・ `raw/papers/ERNIE-Image Technical Report.md`
> 著者・年: ERNIE Team（Baidu）・2026 年・arXiv:2605.25347

## 一言まとめ

**8B の単一ストリーム DiT による text-to-image モデルと、それを支える産業級の美的スコアリングモデル（ERNIE-Image-Aes）を同時に公開したテクニカルレポート**。蒸留では Z-Image の Decoupled DMD / DMDR を土台に、単一教師の **Capability Drift**（能力の漂流）を多教師の動的ルーティングで解消する **MT-DMD** を提案する。

## 背景と問題意識

直前に取り込んだ Z-Image（[[summaries/2025-z-image]]）を**名指しで引き継ぐ**論文である。ERNIE-Image の診断はこうだ——大規模化（Qwen-Image 20B、HunyuanImage）は限界収穫の逓減に直面する。一方で 6B の Z-Image は「有意な可能性を実証しコミュニティから強い評価を得た」が、**複雑な指示追従と中国語のテキストレンダリングでは明確な限界を示す**。そこで 8B で両者の間を狙う。

構成要素の選び方が特徴的で、いずれも**外から借りて小さくする**方向に振れている。

- VAE は **FLUX.2 VAE** をそのまま流用（Z-Image が Flux VAE を流用したのと同じ発想・[[image-tokenizer]]）
- テキストエンコーダは **Ministral-3（3B）** ——意図的に小さい。「小さいテキストエンコーダでも、効果的な条件付け空間を提供しながら長く複雑な指示入力を支えられる」と主張する
- 認知的なギャップは外付けの**プロンプトエンハンサ**で埋める（[[prompt-enhancement]]）

本 wiki にとって最も重要なのは、**美的スコアリングを主題として扱った最初の原典**であることだ。LAION の美的分類器は Wan・Z-Image・HiDream のデータパイプラインで繰り返し登場してきたが、その中身も限界も検討されないまま「品質フィルタ」として使われてきた。ERNIE-Image は §3 を丸ごとこれに充て、**既存予測器を実名で批判し、代替を作り、ベンチマークを公開する**。

## 提案手法 / 主張

### 1. ERNIE-Image-Aes — 美的評価をどう作るか

[[aesthetic-scoring]] に詳述したが、方法論として再利用価値が高い部分を挙げる。

**なぜ絶対評価でなくペアワイズか。** Likert 尺度（1〜10 の点数を独立に付ける）は直感的で効率的だが、**スコアドリフト**——アノテータの暗黙の基準点が時間とともに移動し、**単一のセッション内でさえ初期と後期のラベルが不整合になる**——を被る。ペアワイズは各判断を局所的に接地された二値の決定へ還元するので、この問題を回避する。

**なぜ Elo でなくスイス式か。** Elo は理論的には十分に裏付けられているが、安定したランキングを得るのに**画像あたり法外に多くの比較**を要する。スイス式トーナメント（各ラウンドで現在の順位が近いもの同士を当てる）は、推定品質の近い画像どうしの比較に集中させるので、**大幅に少ない総比較数で信頼できる順位**が得られる。

**品質管理の 2 つの知見**が特に実務的である。

- **アノテータには事前の較正テストが必須**。「美的感度は個人によって相当に異なり、**訓練だけでは確実には改善できない**」——だから育てるのではなく選抜する。
- **複数人が同一トーナメントを共同でアノテートすると破綻する**。異なるアノテータの暗黙の基準が互いに干渉するためで、代わりに**1 人 1 トーナメントを完走させ、後でデータセットの水準で集約**する。「集約は最後にやる」という設計判断である。

### 2. 既存の美的予測器のバイアス — 名指しの批判

本 wiki が繰り返し言及してきた道具への、初めての正面からの検討である。

| 予測器 | 指摘されたバイアス |
| --- | --- |
| **LAION-Aesthetic** | **AI 生成コンテンツとアニメに不釣り合いに高いスコア**。学習データが AI 生成コミュニティ由来であることの直接の帰結。カジュアルなスナップショットも過大評価 |
| **ArtiMuse** | **白黒写真を偏愛**。公園での素人の集団ダンス写真のような日常的な写真にも一貫して高得点 |
| **UniPercept** | 同じく白黒偏重に加え、日常のスナップショットを過大評価 |

ERIA-1K 上の定量比較でも差は大きい。

| Model | SRCC | PLCC |
| --- | --- | --- |
| LAION AES | 0.2944 | 0.3138 |
| ArtiMuse | 0.4277 | 0.4704 |
| UniPercept | 0.4533 | 0.4748 |
| **ERNIE-Image-Aes** | **0.7445** | **0.7598** |

**LAION-Aesthetic の 0.29 という数字は、本 wiki の記述に直接跳ね返る**。[[data-curation]] で整理した通り、Wan も Z-Image も HiDream-I1 も、この予測器を大規模なデータフィルタリングに使っている。それが人間の判断とほとんど相関しないなら、**各社の「高品質データで学習した」という主張の足場が揺らぐ**。

### 3. ERIA-1K — 「現実的な分布」を掲げるベンチマーク

既存の美的ベンチマークは Flickr や DPChallenge 由来で、**専門的な写真コミュニティ・西洋の写真の伝統・視覚的に洗練されたコンテンツへ偏る**。ERIA-1K は 1,000 枚を実世界の分布に近似するよう較正して構成する（写真 49.3%、イラスト／アニメ 23.2%、グラフィックデザイン／ポスター 11.1%、混合 Web 画像 10.4%、フィルム写真 5.4%、製品 0.6%）。アノテータは中央美術学院・四川美術学院・中国伝媒大学などの美術／デザイン／写真の専門的背景を持つ者から募集し、全員が較正の選抜を通過している。

### 4. MT-DMD — 単一教師の限界を突く

蒸留の系譜がここで一段進む。ERNIE-Image はまず既存手法を整理する。

- **Decoupled DMD**（Z-Image）：勾配の干渉を緩和するため、最適化を **CA（CFG-Augmentation）** と **DM（Distribution Matching）** の 2 つの直交する目的へ分岐させる。
- **DMD2**：敵対的に似た地形を安定化させるため、**生成器 1 更新につきスコアモデルを 5 更新**する分離された比率更新。
- **DMDR**：RL と動的ガイダンスを統合。教師スコアモデルに**ステップを意識した LoRA スケーリング**を掛け、実経路のガイダンス強度をコサインスケジュールで変調する：$\alpha_{real}(t)=\frac{\alpha_{init}}{2}[1+\cos(\pi\min(t,T_{dynamic})/T_{dynamic})]$。

> 副次的だが本 wiki には有用な点として、**Z-Image が外部論文に投げていた DMDR の中身がここで読める**。Z-Image の要約で「最も興味深い貢献が本レポート単体では検証できない」と批判したが、その一部がこの論文で補われた形になっている。

その上で ERNIE-Image が指摘する未解決問題が **Capability Drift（能力の漂流）** である。

> 単独の教師は、動的な LoRA ガイダンスと報酬信号で増強されていてさえ、**異種混合のデータに対してすべての意味的領域にわたって一様に最適な教師信号を提供できない**。結果として、判読可能なタイポグラフィのレンダリングや様式化された美しさの維持といった**専門化された部分空間で収束が最適でなくなる**。

解は**専門家教師の委員会** $\mathcal{E}=\{E_1,\dots,E_K\}$（Text-Rendering Expert、Digital Art Expert、マクロ構図の専門家など）を動的ルーティングで束ねることである。

$$\hat{x}_{0}=\sum_{k=1}^{K}\mathcal{W}_{k}(x_{t},\sigma,c,\mathcal{O})\cdot E_{k}(x_{t},\sigma,c)$$

ゲーティング $\mathcal{W}_k$ の条件付けが巧妙で、ノイズ付き潜在 $x_t$・ノイズ尺度 $\sigma$・意味的条件 $c$ に加えて、**最適化目的 $\mathcal{O}\in\{CA, DM\}$ でも切り替える**。ここから 2 つの帰結が出る。

- **非対称な勾配トポロジー**：**同一の学習インスタンスの内部で**、DM 項は Digital Art Expert に問い合わせて大域的な様式の一貫性を強制し、CA 項は Text-Rendering Expert を介して局所的な綴りを独立に最適化する。Decoupled DMD が「CA と DM は別の役割を持つ」と示したことの、**教師割り当てにおける自然な帰結**である。
- **拡散軌道に沿った専門家の引き継ぎ**：高ノイズ域では Spatial Layout の専門家がマクロな構図を確立し、低ノイズ域では高周波のレンダリングの専門家（写実的な照明、材質のテクスチャ）へ移行する。[[diffusion-sampling]] で見てきた「タイムステップによって仕事の内容が違う」という理解が、教師の使い分けとして実装されている。

### 5. Flow Matching 上の DPO と Anchor Loss

[[reinforcement-learning-for-diffusion]] にとって具体的な処方箋になる部分である。速度場の L2 再構成誤差を暗黙の報酬として、勝ち画像と負け画像の誤差の差を方策と参照モデルの双方で取り、その相対ギャップを最大化する。

$$\mathcal{L}_{\mathrm{DPO}}=-\mathbb{E}[\log\sigma(-\beta(\text{Diff}_{\mathrm{policy}}-\text{Diff}_{\mathrm{ref}}))]$$

**失敗モードの記述が明快である**。素朴に適用すると、モデルは **L2 損失が非有界であることを悪用し、拒否サンプルの誤差を際限なく膨らませるだけで報酬を稼ぐ**——これが典型的な報酬ハッキングで、しばしば表現の崩壊に至る。「良い方を良くする」より「悪い方を無限に悪くする」方が簡単だからである。

対処が **Anchor Loss**：勝ち・負けの**両方**に通常の flow matching 損失を足して、基礎的な生成能力に錨を下ろす。

$$\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{DPO}}+\lambda_{win}\mathbb{E}[\ell^{win}]+\lambda_{lose}\mathbb{E}[\ell^{lose}]$$

係数まで公開されている（$\beta=0.05$、$\lambda_{win}=0.35$、$\lambda_{lose}=0.15$）。**負け側にも 0.15 の重みを残す**のが要点で、「拒否サンプルでも、まともな画像であり続けよ」という制約になっている。

なお著者らは「**ベースモデルと報酬モデルの双方が十分に強力であれば、望ましい状態に達するのに必要な DPO のステップはごくわずか**」とも述べており、報酬ハッキングを最小化する実務的な戦略として記録に値する。

### 6. データ：ボトムアップという対比

[[data-curation]] の文脈で明示的な対比が置かれている。**事前学習はボトムアップ**——膨大な生コーパスから始め、10,000 の細粒度カテゴリへの分類・キャプションの充実・美的スコアリング・階層的サンプリングを通じて**漸進的に構造を課す**。**事後学習（SFT）はトップダウン**——優先領域（ポスターデザイン、ゲーム画面、人物写真、物撮り、アニメ）を先に決めてからデータをキュレートする。Z-Image が「トップダウンの再サンプリング」と呼んで対置したものが、ここでは事後学習側に配置されている。

階層的サンプリングの設計も具体的である：**カテゴリ間**ではコーパス規模と集約された美的品質の**両方**で重みを決め、**カテゴリ内**では個々の美的スコアでサンプリングする。美的スコアがフィルタではなく**サンプリング確率**として使われている点が、単なる足切りより踏み込んでいる。

## 実験結果と知見

- **人間評価**（表3・社内テストセット、7 次元）: 総合 5.07 で **2 位、オープンソース 1 位**。Nano Banana 2.0（5.39）に次ぎ、Seedream 5.0（5.03）・Wan2.7-Image（4.96）・Qwen-Image-2512（4.78）・Z-Image-Turbo（4.56）を上回る。
- **GenEval**（表4）: **ERNIE-Image（PE なし）が 0.89 で最高**。Position が 0.86 と突出しており（Qwen-Image 0.76、Z-Image 0.62）、空間関係の指示追従という長年の弱点で明確に前進している。
- **LongText-Bench**（表5）: 総合 **0.973**（英 0.980 / 中 0.966）。Qwen-Image-2512（0.960）、Z-Image（0.936）を上回る。英中の差が小さいことが強調される。
- **OneIG-EN**（表6）: **ERNIE-Image（PE あり）が 0.575** で、クローズドソースの Nano Banana 2.0（0.578）に肉薄。Z-Image（0.546）、Qwen-Image（0.539）を上回る。
- **OneIG-ZH**（表7）: 0.554 で、Nano Banana 2.0（0.567）に次ぎ **オープンソース 1 位**。

**PE のありなしを両方報告している点が、本 wiki にとって特に価値がある**。Z-Image の要約で「評価が PE 込みか否かが曖昧で、実効規模が不透明」と批判した論点に、この論文は正面から答える形になっている。しかも結果が一様でない。

| ベンチマーク | PE なし | PE あり | 差 |
| --- | --- | --- | --- |
| GenEval 総合 | **0.89** | 0.87 | **PE で下がる** |
| OneIG-EN 総合 | 0.554 | **0.575** | PE で上がる |
| OneIG-EN の Reasoning | 0.295 | **0.357** | 大幅に上がる |
| OneIG-EN の Diversity | 0.169 | **0.241** | 上がる |
| OneIG-EN の Alignment | **0.891** | 0.868 | 下がる |
| LongText-Bench 総合 | 0.964 | **0.973** | 上がる |

読み取れるのは、**PE は推論と世界知識を要する次元を大きく押し上げる一方、素朴な整合や物体属性の遵守では邪魔になりうる**ということである。GenEval のような「プロンプトに書かれた通りに置く」タスクでは、プロンプトを膨らませることが**元の指定を薄める**方向に働く。[[prompt-enhancement]] の「ユーザーの意図の書き換え」という限界が、数字で見える形になった数少ない例である。

**PE の規模比較**（§4.1）も記録に値する。3B の PE でも構造化された生成（ホワイトボードの数式、RPG の HUD、Web ページのレイアウト）に実践的な利得が出る一方、**より大きな LM の PE は世界知識と推論を要するタスクでさらに伸びる**——ホワイトボードの例では数学的導出の正確さと完全性に差が出る。「PE は表面的な前処理ではなく、長いプロンプトによる生成能力を解き放つ機構」という結論になっている。

## 限界・批判的視点

- **MT-DMD にアブレーションがない**。専門家教師が何人いるのか（$K$ の値）、ゲーティングネットワークをどう学習するのか、単一教師の DMDR と比べてどれだけ良くなったのか——**いずれも数値が示されない**。Capability Drift という問題設定は説得的だが、それが解決されたという証拠は提示されていない。§2.2.3 全体が定性的な記述に終始する。
- **人間評価の「Total HP」の定義が不明**。5.39 や 5.07 という値が、7 次元の合格率（いずれも 50〜99% の範囲）とどう関係するのかが書かれていない。7 次元の平均でも合計でもない。**看板の順位を支える指標の算出方法が説明されていない**。
- **テストセットが社内かつ非公開**。「ユーザーのフィードバックに基づく社内テストセット」であり、内容も規模も公開されない。1 位を主張する根拠が検証できない。
- **ERNIE-Image-Aes の評価が自己循環的である**。ERNIE-Image-Aes は「内部でアノテートされたデータセット」で学習され、ERIA-1K で評価される。ERIA-1K も**同じチームが同じスイス式プロトコルで同種のアノテータに作らせたもの**である。競合（LAION AES 0.29、ArtiMuse 0.43）との 0.3 ポイント差の一部は、**プロトコルと評価者集団の一致**によるものかもしれない。他のベンチマーク（AVA など既存の美的データセット）での評価がないため、切り分けられない。
- **アーキテクチャの記述が極端に薄い**。「8B の単一ストリーム DiT」以外に、層数・隠れ次元・注意機構・位置符号化・正規化の記述が一切ない。Z-Image が表 2 で構成を公開したのと対照的で、**「単一ストリーム DiT」という言葉だけでは Z-Image の S3-DiT との異同が分からない**（[[diffusion-model-architecture]]）。
- **Ministral-3 を選んだ根拠がない**。「小さいテキストエンコーダでも支えられることを実験を通じて見出した」と述べるが、**その実験は示されない**。Wan が umT5 対 Qwen2.5-7B 対 GLM-4-9B を実際に比較した（[[summaries/2025-wan]]）のとは水準が違う。
- **学習コストが非公開**。Z-Image が 314K H800 GPU 時間・$628K を段階別に公開したのに対し、ERNIE-Image は「費用対効果が高い」と主張しながら数字を出さない。直接比較ができない。
- **Diversity が低い傾向は共通**。OneIG-EN で PE なしの ERNIE-Image-Turbo は 0.123 と、比較対象中でも最低水準（Z-Image-Turbo 0.139 と同じ問題）。**蒸留と SFT が多様性を削る**という [[diffusion-distillation]] の既知の限界がここでも出ているが、議論されない。
- **ERIA-1K のライセンスと配布形態が不明**。「公開する」と述べるが、画像そのものの権利処理には触れられていない。美的ベンチマークは実写画像を含むため、この点は実務上重要である。
- **図の欠落**。ar5iv 側で図 5（美的予測器のバイアス比較）・図 6（PE 比較の 3×3）・図 8・図 11 が分解されており、とくに図 5 の**バープロットは 9 パネルすべてで同一 SVG が重複参照される形に変換されていて、パネルごとのスコアが失われている**。標本画像は arXiv から回収したが、バイアスの定量的な提示は原典の PDF でしか確認できない。

## 用語と略称

- **LDM** = Latent Diffusion Model（潜在拡散モデル）。VAE で圧縮した潜在空間で拡散を行う枠組み。
- **DiT** = Diffusion Transformer。**単一ストリーム DiT**：テキストと画像のトークンを共有重みで処理する構成。
- **VAE** = Variational Autoencoder。ここでは FLUX.2 VAE を流用。
- **VLM** = Vision-Language Model（視覚言語モデル）。キャプション生成に使用。
- **NFE** = Number of Function Evaluations。画像 1 枚の生成にネットワークを呼ぶ回数。
- **DPO** = Direct Preference Optimization。選好ペアから方策を直接最適化する手法。
- **Anchor Loss**：DPO に通常の再構成損失を足して基礎能力に錨を下ろす正則化。
- **reward hacking（報酬ハッキング）**：報酬関数を悪用して高スコアだが望ましくない出力を作る現象。
- **DMD** = Distribution Matching Distillation。**DMD2**：スコアモデルと生成器の更新比率を分離した改良。**Decoupled DMD**：CA と DM に分岐させる改良。**DMDR**：DMD に RL と動的ガイダンスを統合。**MT-DMD**：本論文の多教師版。
- **CA** = CFG-Augmentation。教師の誘導された経路との軌道の整合を強制する項。**DM** = Distribution Matching。生成分布と経験分布の乖離を最小化する項。
- **Capability Drift（能力の漂流）**：単一の教師が異種混合データのすべての領域で一様に最適な教師信号を出せないこと。
- **LoRA** = Low-Rank Adaptation。ここでは教師スコアモデルへの動的スケーリングに使用。
- **PE** = Prompt Enhancer（プロンプトエンハンサ）。短いユーザー入力を詳細な記述へ展開する。
- **SFT** = Supervised Fine-Tuning。
- **SRCC** = Spearman's Rank Correlation Coefficient（順位相関）。**PLCC** = Pearson's Linear Correlation Coefficient（線形相関）。いずれも予測スコアと人間のラベルの一致度を測る。
- **Likert 尺度**：1〜10 のような離散的な評点を独立に付ける絶対評価。**スコアドリフト**：その基準点が時間とともに移動する現象。
- **Elo レーティング**：一対一の勝敗から強さを推定する方式。**スイス式トーナメント**：各ラウンドで現在の順位が近い者どうしを当てる方式。
- **ERIA-1K** = ERNIE-Image-Aes-1K。本論文が公開する 1,000 枚の美的ベンチマーク。
- **LAION-Aesthetic / ArtiMuse / UniPercept**：既存の美的スコアリングモデル。本論文が批判の対象とする。
- **GenEval / OneIG-Bench / LongText-Bench**：text-to-image のベンチマーク。
