# Qwen-Image-VAE-2.0 — 高圧縮・高忠実・拡散しやすい潜在空間を同時に得る

> 原典: [[translations/2026-qwen-image-vae-2]] ・ `raw/papers/Qwen-Image-VAE-2.0 Technical Report.md`
> 著者・年・出典: Qwen Team（Alibaba）, arXiv:2605.13565, 2026年

## 一言まとめ

[[latent-diffusion]] の「土台」である **VAE（画像トークナイザ）だけを主題にした論文**。空間圧縮率を業界標準の 8 倍から **16 倍・32 倍**へ引き上げつつ、**圧縮率・再構成忠実度・拡散可能性（diffusability）という三者間トレードオフ**を、Global Skip Connection＋大チャネル＋DINOv2 中間層への意味的整合で同時に解く。**f16c128 は文書テキストの再構成でついに全 f8 VAE を上回った**（NED 0.9617 対 FLUX.1-dev 0.9546）。Qwen-Image-2.0（[[summaries/2026-qwen-image-2]]）の中で実際に使われている。

## 背景と問題意識

[[latent-diffusion]] では、画像をそのまま拡散させず VAE で潜在に圧縮してから拡散する。この圧縮率 $f$（8 倍なら $f8$）は長らく 8 が標準だった。しかしネイティブ高解像度生成の時代になると、これが効率の壁になる——**DiT の計算量は潜在トークン数に対して二次的に増える**ため、$f$ を上げると計算量は $\mathcal{O}(H^2W^2/f^4)$ で劇的に下がる。$f8 \to f16$ で系列長は 1/4、計算量は約 1/16 になる。

ところが圧縮率を上げると別の問題が噴出する。本論文が「**三者間トレードオフ（tripartite trade-off）**」と呼ぶものである。

1. **圧縮率**を上げたい（DiT を速くしたい）
2. しかし**再構成忠実度**が落ちる（情報が入りきらない。とくに小さな文字が壊滅する）
3. 忠実度を戻そうと**潜在チャネル $C$ を増やす**と、今度は潜在分布が複雑・非構造的になり、**拡散モデルが学習しにくくなる**

この 3 番目が「**拡散可能性（diffusability）**」——「その潜在空間がどれだけ拡散モデルでモデル化しやすいか」という、再構成品質とは独立した性質である。再構成が完璧でも、潜在が拡散しにくければ下流の生成モデルは収束せず役に立たない。**本論文の主題はこの三竦みを同時に解くこと**にある。

## 提案手法 / 主張

### 設計原則：情報ボトルネックは $N(z)=CHW/f^2$

出発点は明快な等式である。再構成忠実度を支配するのは**総情報ボトルネック** $N(z)=CHW/f^2$ であり、$f$ を上げて失った分は $C$（チャネル）を増やせば補償できる。しかも重要なのは、**チャネルを増やしても DiT の学習効率は落ちない**点——DiT は最初に線形層で潜在を固定の隠れ次元へ射影するので、計算量はチャネル数にほぼ不変だからである。よって「$f$ を上げ、$C$ で埋める」が正しい方向になる。残る問題は 3 番目（拡散可能性）だけになる。

### アーキテクチャの 3 つの手

</figure>

- **Global Skip Connection（GSC）**：高圧縮の最大の敵は、エンコーダの初期ダウンサンプリングで高周波情報が落ちること。GSC は **space-to-channel 操作**（空間の情報をチャネル次元へ折り畳む）で、ピクセルから潜在への大域的な近道を作る。アブレーション（NSC / LSC / GSC）で収束が明確に速くなることを確認。
- **Attention-free バックボーン**：自己注意は計算もメモリも $\mathcal{O}(N^2)$ で、高解像度ではスループットの致命傷になる。畳み込みは $\mathcal{O}(N\cdot k^2)$。「注意を外しても性能が落ちなかった」ので全系列から除去した。
- **エンコーダ・デコーダの非対称化**：エンコーダは軽く（76〜78M）、デコーダは重く（248〜250M）。理由が実務的で面白い——**エンコーダは拡散モデルの学習中に毎回走る**ので軽い方が学習が速くなり、デコーダは推論時に 1 回だけなので重くてよい。

構成は f16c64 / f16c128 / f32c128 / f32c192 の 4 種。

### 学習：KL も GAN も捨てる

損失は $\mathcal{L}_{total}=\mathcal{L}_{recon}+\lambda_{lpips}\mathcal{L}_{lpips}+\lambda_{align}\mathcal{L}_{align}$ の 3 項のみ。VAE の教科書的な構成要素を 2 つとも外した点が主張である。

- **KL 損失を外す**：KL は潜在を正規分布へ寄せる正則化だが、(1) 潜在容量を制約して再構成を損なう、(2) より重要な点として、**意味的整合と competing な制約になる**——目標の意味特徴はガウス分布ではないので、「正規事前分布」と「意味的多様体」の両方を満たせと強いると整合が中途半端になり、下流 DiT の収束がかえって遅れる。
- **GAN 損失を外す**：学習予算が十分大きければ、再構成損失＋知覚損失（LPIPS）だけで十分鋭い再構成が得られる。識別器を消すと最適化が単純になり安定性と速度が上がる。（初代 Qwen-Image でも「品質が上がると識別器が有効な勾配を出せなくなる」と報告済み。）

### 拡散可能性の鍵：DINOv2 の「中間層」への意味的整合

VA-VAE に倣い、潜在を事前学習済み視覚エンコーダの特徴へ整合させる。ここでの発見が 2 つある。

- **どのエンコーダか**：DINOv2・DINOv3・MAE・PE-Spatial を比較し、**DINOv2 が一貫して最良**。DINOv2-L を採用。
- **どの層か**：慣例では最終層を使うが、**中間層の方が空間マップが滑らかで整合しやすく、より生成に適した潜在空間になる**。しかも複数層を素朴に混ぜるとノイズが入って逆効果なので、**最適な単一の中間層**だけを使う。

損失は 2 つの組み合わせ：**Marginal Cosine Similarity**（潜在の向きを意味特徴に合わせる）と **Marginal Distance Matrix Similarity**（位置ペア間の類似度構造＝相対的な空間レイアウトを保つ）。どちらも ReLU でマージンを設け、「十分近ければ罰しない」形にしてある。

さらに**段階的整合**——学習初期は厳しいマージンで強く整合させ（これが拡散可能性の確立に効く）、進むにつれ緩めて再構成品質とのバランスを取る。

### データ：合成テキストは「背景付き」でなければ効かない

数十億枚へスケールし、OCR フィルタで文字密度の高い実画像を優先、学術論文・スライド・ポスター・ウェブページの文書コーパスを精選。加えて文書レンダリングの合成パイプラインを作るが、ここに実務的な知見がある——**白背景に黒文字のような「背景なし」合成データで学習したモデルは、複雑なテクスチャの上に文字が乗る実世界画像へ汎化しない**。そこで一般画像からランダムに背景を選んでその上にテキストをレンダリングする「背景込み合成」にした。さらに 5〜20 ピクセルの文字サイズで難易度を変え、$f32$ でも判読性が残るようにしている。

## 実験結果と知見

### 新ベンチマーク OmniDoc-TokenBench

**なぜ必要か**：ImageNet や FFHQ は自然写真ばかりでテキストがない。そして PSNR/SSIM は**文字の判読性に鈍感**である——「orange」が「orango」になっても PSNR は 0.5 dB も落ちないが、意味は壊れている（NED は 16.7% 落ちる）。

そこで約 3K 枚の文書画像（書籍・スライド・教科書・試験問題・論文・雑誌・財務報告・新聞・ノートの 9 カテゴリ、中英）を精選し、**OCR ベースの NED（Normalized Edit Distance）** で測る。設計上の白眉は、**正解アノテーションではなく「元画像を OCR した結果」を参照にする**こと。OCR 自体がクリーンな画像でも誤る（「rn」を「m」と読むなど）ので、両方に同じ OCR をかければその系統誤差が相殺され、**VAE の再構成劣化だけを切り分けられる**。アノテーション不要なので新しい文書型へ拡張しやすい利点もある。

### 結果

- **一般再構成**（表2）：各圧縮階層で SOTA。特筆すべきは **f32c192 が 4 倍高い圧縮率にもかかわらず f8 の Wan2.1 に匹敵**すること。
- **テキスト再構成**（表3）：**f16c128 が NED 0.9617 で、評価した全 f8 VAE を上回る**（FLUX.1-dev 0.9546）。著者らは「**f8 VAE を超えるテキスト忠実度を達成した初の f16 オートエンコーダ**」と主張。SSIM 0.9706・PSNR 30.45 dB も f8 最良（0.9364 / 26.24）を上回る。f32c192 でも NED 0.8555 と、複数の f16 ベースラインを超える。
- **ピクセル指標と NED は一致しない**：Stepvideo-T2V は HunyuanImage-3.0 より SSIM 差はわずかなのに NED は大きく上（0.8838 対 0.7753）。LTX-Video は FID が悪いのに NED は上。**NED が独立に必要な指標であることの実証**になっている。
- **拡散可能性**（表2 の生成列）：ImageNet で SiT を 80 エポック学習し IS / gFID で測ると、Qwen-Image-VAE-2.0 は高圧縮ベースラインを一貫して上回る（f16c64 で IS 102.76 / gFID 9.52）。大きなチャネル次元でも収束が速いことを示し、三者間トレードオフが解けたと主張する。
- **大規模検証**：Qwen-Image-2.0 に実際に組み込まれて動いていること自体が、基盤モデル規模での拡散可能性の証拠だとする。

## 限界・批判的視点

- **拡散可能性の評価が ImageNet の SiT に限られる**。80 エポック・CFG なしという限定的な設定で、実際の大規模 T2I での収束曲線の比較はない（Qwen-Image-2.0 での採用は定性的な言及にとどまる）。
- **f16c64（Qwen-Image-2.0 が実際に採用した構成）は f16c128 ほど強くない**。NED 0.9244 は f8 最良には届かず、テキスト忠実度を最優先するなら c128 を選ぶべきという含意になる。論文内に両者のトレードオフの議論は薄い。
- **KL 除去の帰結が論じられていない**。KL がないと潜在は厳密には確率的な「変分」オートエンコーダでなくなり（実質的に正則化付き AE）、サンプリングや潜在空間の滑らかさへの影響は検討されていない。
- **意味エンコーダへの依存**。DINOv2 という外部の事前学習モデルに潜在空間の質が左右される構造で、その選択・層の選択は経験則である。
- OmniDoc-TokenBench は OCR モデル（PP-OCRv5）に依存し、テキスト正規化なしの生出力を使うため字間のアーティファクトが編集距離を膨らませうる（著者も認める）。

## 用語と略称

- **VAE** = Variational AutoEncoder（変分オートエンコーダ。ここでは画像を潜在へ圧縮・復元する画像トークナイザ）。
- **$f$ / $C$**：空間圧縮率（$f16$ なら縦横 1/16）と潜在チャネル数。**$f16c64$** は「16 倍圧縮・64 チャネル」。
- **diffusability（拡散可能性）**：その潜在空間がどれだけ拡散モデルで学習しやすいか。再構成品質とは独立の性質。
- **三者間トレードオフ**：圧縮率・再構成忠実度・拡散可能性の三竦み。
- **GSC** = Global Skip Connection（大域スキップ接続。space-to-channel でピクセル情報を潜在へ直送）。**NSC / LSC** はスキップなし／局所スキップ。
- **S2C** = Space to Channel（空間情報をチャネル次元へ折り畳む操作）。
- **attention-free**：自己注意を使わない（畳み込みのみの）構成。
- **LPIPS** = Learned Perceptual Image Patch Similarity（知覚的類似度。人間の見た目に近い距離）。
- **semantic alignment loss（意味的整合損失）**：潜在を事前学習済み視覚エンコーダの特徴へ揃える損失。
- **DINOv2**：自己教師あり学習で得た汎用視覚特徴抽出器。ここでは意味的整合の教師。
- **VA-VAE**：意味的整合で潜在を拡散しやすくする先行研究。
- **NED** = Normalized Edit Distance（正規化編集距離。1 に近いほど文字列が一致）。**Levenshtein 距離**に基づく。
- **OCR** = Optical Character Recognition（光学文字認識）。ここでは PP-OCRv5 を使用。
- **PSNR / SSIM / FID**：ピーク信号対雑音比／構造的類似性／Fréchet Inception Distance（**gFID** は生成画像に対する FID）。
- **IS** = Inception Score（生成画像の品質・多様性の指標。高いほど良い）。
- **SiT**：拡散／フローベースの Transformer 生成モデル。ここでは拡散可能性を測る下流モデルとして使用。
- **KL ダイバージェンス**：分布間の距離。通常の VAE では潜在を正規分布へ寄せる正則化に使うが、本論文は除去した。
